# 앱 구조도

프로그램 구성을 한 장씩 설명한 자료. HTML을 브라우저에서 열어 인쇄하거나,
`shot.py` 방식으로 다시 렌더링해 PNG를 갱신할 수 있다.

| 장 | 내용 |
|---|---|
| `1-journey` | 학생이 겪는 흐름 — 가입부터 매일의 세션, 잠금 규칙, 오답 간격 반복 |
| `2-curriculum` | 커리큘럼 — 기간 4종 × 방식 2종의 트랙 배치와 기간별 설계값 |
| `3-system` | 시스템 구성 — 화면·데이터·AI 작업 계층, 콘텐츠 제작 파이프라인, 보안·비용 |
| `4-screens` | 화면 구성 — 오늘의 과제·에세이 채점 화면 구조와 라우트 지도 |

수치는 실제 생성된 실라버스(`data/syllabus/`)와 설정(`config/durations.json`)에서
가져온 값이다. 커리큘럼을 다시 생성하면 이 자료의 숫자도 함께 갱신해야 한다.

렌더링은 1600px 폭, 2배 스케일 기준.
