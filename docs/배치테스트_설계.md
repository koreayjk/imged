# 배치 테스트 설계 — 레벨(상/중/하) 산정

> 온보딩 흐름과 레벨별 실라버스 규칙을 정의한다.
> 레벨별 스킵 규칙의 실체는 `config/levels.json`, 산출물은 `docs/syllabus/실라버스_<기간>_<레벨>.md`.

---

## 1. 온보딩 흐름 (학생 등록 시)

```
① 기본 정보 + 모국어 선택            (관리자 입력)
② 목표 기간 선택: 6개월 / 1년 / 2년 / 3년
③ 배치 테스트 응시: 수학 + 영어      (앱 내 자체 문항)
④ 자동 레벨 산정: 과목별 상/중/하    (관리자 검토 후 확정)
⑤ 기간 × 레벨 조합으로 로드맵 생성   (관리자 조정 → 확정)
```

- **기간**은 학생·관리자가 정하는 "시간" 설정이고, **레벨**은 테스트가 정하는 "난이도" 설정이다.
- 관리자는 산정된 레벨을 수동으로 올리거나 내릴 수 있다 (테스트 컨디션 문제 등).

## 2. 테스트 구성

| 과목 | 문항 수 | 범위 | 제한 시간 |
|---|---|---|---|
| 수학 | 30문항 | 산수 10 + Pre-algebra 12 + 대수 기초 8 | 45분 |
| 영어 | 25문항 | 문법 15 (품사·구두점·문장구조) + 독해 10 (단문 지문) | 40분 |

- 자체 문제은행에서 출제 (skill_tag별 균등 추출). Khan Course Challenge를 보조 진단으로 활용 가능 (설계 문서 §1-⑤).
- 과학·사회는 배치 테스트를 보지 않는다 — 이 과목들의 병목은 배경지식이 아니라 **영어 독해력**이므로 영어 레벨을 따른다.

## 3. 레벨 산정 컷라인 (과목별 독립)

| 정답률 | 레벨 | 의미 |
|---|---|---|
| 0–49% | **하 (기초)** | 전 과정 처음부터 |
| 50–79% | **중 (중급)** | 기초 유닛 스킵 |
| 80–100% | **상 (상급)** | 입문 과정 스킵 + 상위 티어 확장 |

**과목별 독립 적용**: 영어 상급 + 수학 하급 같은 조합이 가능하다. 앱의 로드맵 생성기는
영어 레벨 → 영어 트랙, 수학 레벨 → 수학 트랙(+선행 트랙), 영어 레벨 → 과학·사회 트랙 순서로 조합한다.
`docs/syllabus/`의 12개 실라버스 문서는 **전 과목 동일 레벨 가정의 참조본**이며, 실제 학생별 로드맵은 조합으로 생성된다.

## 4. 레벨별 차이 요약

| | 하 (기초) | 중 (중급) | 상 (상급) |
|---|---|---|---|
| 산수(선행) | 전체 수강 | **스킵** | **스킵** |
| Pre-algebra | 전체 | 기초 정수·패턴 스킵 | 중학 초반 10개 유닛 스킵 |
| 기초 기하 | 전체 | 기초 측정 스킵 | 기초 측정+평면도형+좌표 스킵 |
| 영문법 | 전체 | 기초 품사 3유닛 스킵 | **전체 스킵** → SAT 독해·작문부터 |
| 중학 과학(선행) | 전체 | 전체 | **스킵** |
| 티어 | 기간 기본값 | 기간 기본값 | **+1** (예: 6개월 T1→T2 = 확률·통계 추가) |
| 상급 확장 코스 | — | — | Algebra 1 (수학), SAT R&W 풀버전 (영어) |
| 스킵으로 남는 시간 | — | 레슨당 예제 영상 확충 | 예제 확충 + 상위 콘텐츠 |

## 5. 진행 중 재배치 (앱 구현 요구사항)

- **상향 제안**: 첫 2주 정답률 90% 이상 + 예정보다 빠른 진도 → 관리자에게 레벨 상향 제안 알림
- **하향 보호**: 2주 연속 정답률 40% 미만 → 레벨 하향 + 스킵했던 기초 유닛을 보충 계획으로 삽입 제안
- 레벨 변경 시 로드맵은 **현재 위치를 보존한 채 잔여 구간만 재생성**한다 (이수 이력 유지)
- 스킵된 영상 목록(`제외목록_*.md` = `트랙별 trim 데이터`)은 취약 스킬 보충 계획의 1순위 소스다
