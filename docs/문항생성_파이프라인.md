# 문항 AI 대량 생성 + 검수 파이프라인

## 원칙

**공식 GED 문항을 복제하지 않는다.** GED Testing Service의 공식 시험 사양(assessment targets,
도메인 비중, 문항 유형, 출제 스타일)을 *사양서*로 삼아 AI가 **새 문항을 생성**하고, 사람이 검수한다.

## 구성 요소

| 파일 | 역할 |
|---|---|
| `config/blueprint/ged_blueprint.json` | 4과목 시험 스펙 — 도메인 비중, 문항 유형 믹스, 출제 스타일, 품질 규칙 |
| `config/blueprint/ged_math_targets.json` | 수학 공식 assessment target 48개 (코드 + 설명) |
| `scripts/generate_questions.py` | Gemini로 문항 생성 → 자동 검증 → `config/generated/`에 저장 |
| `supabase/migrations/0004_question_review.sql` | 검수 메타 컬럼 + `review_question()` RPC |
| 앱 `/review` 화면 | 관리자가 문항을 하나씩 보며 승인/반려 |

## 흐름

```
공식 스펙(blueprint) ──┐
                      ├─→ Gemini 생성 → 자동 검증 → status='draft' → 관리자 검수 → 'published'
기존 문항(중복 방지) ──┘                                                        └→ 'rejected'
```

**자동 검증 항목** (통과 못 하면 저장하지 않음)
- 보기 정확히 4개, 중복 없음 / 정답 인덱스 유효
- "위의 모두", "정답 없음" 류 보기 금지
- 영어 문두 + 한국어 번역 + 양쪽 해설 모두 존재
- 기존 문제은행과 문두 중복 아님

## 사용법 (권장: 앱에서 버튼 클릭)

관리자로 로그인 → **문항 검수** 메뉴 → **문항 생성** 패널에서 과목·개수 선택 → **🤖 AI로 문항 생성**.
Edge Function `generate-questions`가 실행되어 생성·검증·저장까지 끝내고, 바로 아래 검수 목록에 나타난다.
로컬 터미널·API 키·시드 SQL이 필요 없다.

- 배포: 대시보드 → Edge Functions → New function `generate-questions` →
  `supabase/functions/generate-questions/index.ts` 붙여넣기 → Deploy
- 시크릿: `GEMINI_API_KEY` (에세이 채점과 공유)
- 권한: 관리자(`profiles.role='admin'`)만 호출 가능

## 사용법 (대안: 로컬 스크립트)

```bash
export GEMINI_API_KEY=AIza...          # https://aistudio.google.com/apikey

# 수학: 공식 타깃 48개 × 3문항 = 약 144문항
python scripts/generate_questions.py --subject math --per-target 3

# 영어/과학/사회: 도메인 비중대로 60문항씩
python scripts/generate_questions.py --subject rla --count 60
python scripts/generate_questions.py --subject science --count 60
python scripts/generate_questions.py --subject social --count 60

# 프롬프트만 확인 (API 호출 없음)
python scripts/generate_questions.py --subject math --dry-run
```

생성 결과는 `config/generated/<subject>_<타임스탬프>.json`에 저장된다.
DB에 올리려면 시드 SQL을 재생성해 Supabase에서 실행한다:

```bash
python scripts/generate_seed_sql.py     # generated/ 포함해 시드 SQL 갱신
```

## 검수

1. 관리자 계정으로 앱 로그인 → 상단 **문항 검수** 메뉴
2. 문항별로 문제·보기·정답·해설(영/한)·오답 설계 근거를 확인
3. **승인** → `published`(학생에게 노출) / **반려** → `rejected` / **건너뛰기**
4. 메모를 남기면 `questions.review_note`에 기록된다

## 목표 규모

| 단계 | 문항 수 | 비고 |
|---|---|---|
| 현재 (수작업) | 144 | 검증 완료, published |
| 1차 생성 | +300~400 | 수학 우선 (파일럿 20주분) |
| 최종 목표 | 약 3,600 | 4과목 × skill_tag 60개 × 15문항 (설계 문서 §7) |
