# 에세이 AI 채점 설계 (GED Extended Response)

## 채점 기준 — GED 공식 3-트레이트 루브릭 (각 0~2점, 총 6점)

| 트레이트 | 평가 내용 |
|---|---|
| ① 논증·근거 사용 | 지문 기반 주장 수립, 구체적 근거 인용, 입장의 명확성 |
| ② 전개·구성 | 논리적 전개, 서론-본론-결론 구조, 연결어 사용 |
| ③ 문장·문법 정확성 | 문장 다양성, 문법·어법·구두점·철자 (이해를 방해하지 않으면 감점 최소화) |

45분 초안 기준으로 채점 (완성 에세이 기준 아님). 빈 답안·주제 이탈·지문 베끼기는 전 항목 0점.

## 파이프라인

```
학생 (앱 /essay)
  └─ 주제 선택 → 지문 읽기 → 45분 타이머 + 에디터 작성 → 제출
       └─ supabase.functions.invoke('grade-essay')   ← 로그인 JWT 자동 첨부
            └─ Edge Function (Deno):
                 1. JWT 검증 (auth.getUser)
                 2. Claude API 호출 (claude-opus-5, structured output=Zod 스키마)
                 3. essays 테이블에 본문+점수+피드백 저장 (RLS: 본인 행)
                 4. 채점 JSON 반환
       └─ 결과 화면: 총점/6, 트레이트별 점수 바 + 코멘트(모국어),
          잘한 점 / 보완할 점 / 문법 교정(원문 인용→수정문) / 다음 연습 방향
```

- 피드백 언어: 학생 모국어(ko/zh/th) 우선 + 영어 병기 필드
- 모델: `claude-opus-5` (Anthropic 최신 Opus). 문항당 비용 대략 $0.05~0.15 수준
- structured output(`output_config.format` + Zod)으로 점수 형식이 항상 보장됨

## 배포 절차 (1회)

1. **마이그레이션**: Supabase SQL Editor에서 `supabase/migrations/0003_essays.sql` 실행
   (essay_prompts·essays 테이블 + RLS + 스타터 프롬프트 2개)
2. **Anthropic API 키 발급**: https://console.anthropic.com → API Keys
3. **Edge Function 배포** (둘 중 하나):
   - CLI: `supabase functions deploy grade-essay && supabase secrets set ANTHROPIC_API_KEY=sk-ant-...`
   - 대시보드: Edge Functions → Deploy new function → 이름 `grade-essay` →
     `supabase/functions/grade-essay/index.ts` 내용 붙여넣기 → Deploy →
     Settings → Edge Functions → Secrets 에 `ANTHROPIC_API_KEY` 추가

## 확장 계획

- 에세이 이력 화면 (essays 테이블 조회) + 점수 추이 그래프
- 관리자: 학생 에세이·AI 피드백 열람, 필요 시 코멘트 덧붙이기
- 재작성(revision) 루프: AI 개선점 반영해 다시 제출 → 점수 변화 추적
- 프롬프트를 DB(essay_prompts)에서 로드해 관리자가 직접 추가 (현재는 번들 JSON과 병행)
