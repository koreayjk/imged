# 실라버스

> **입학 기준 — 영어 CEFR B1 이상.** GED 과학·사회는 암기가 아니라 영어 지문 분석 시험이라,
> B1 미만이면 4과목을 동시에 따라갈 수 없다. 이 기준 덕분에 선행(중학) 과정과 영어 품사 기초를
> 빼고 첫날부터 4과목을 병행한다.

기간 2종 × 레벨 3종 = **6종**. 모두 `scripts/generate_syllabus.py`가 `config/`의 설정에서
자동 생성한다. 손으로 고치지 말고 설정을 고친 뒤 다시 생성할 것.

```
python3 scripts/generate_syllabus.py          # 전체
python3 scripts/generate_syllabus.py 6m basic # 기간·레벨 키로 부분 생성
```

## 설계 요약

| | 6개월 집중 | 1년 정규 |
|---|---|---|
| 기간 | 26주 · 130일 | 52주 · 260일 |
| 하루 | 240분 (4시간) | 180분 (3시간) |
| 세션 | 워밍업 15분 → 4과목 → 체크인 10분 | 동일 |
| 과목 배치 | 첫날부터 영어·수학·과학·사회 매일 | 동일 |
| 심화 | — | 대수 1 · SAT 수학 · 미국사 심화 · 거시경제 |
| 서술형 | 매주 금요일 영어 시간 (22회) | 매주 금요일 (44회) |

**영상 비중**: 트랙 학습의 40%가 영상, 60%가 문항 풀이. 단 **영어는 20%** — B1 이상을 전제하므로
보는 것보다 읽기·문항·서술형 작성에 시간을 쓴다. 영어 영상은 86편(중복 제거 후)뿐이라 기간 전체에
고르게 펴서 배치하고, 나머지 시간은 문항과 에세이로 채운다.

## 숫자 읽는 법

**주제(레슨) 수가 커버리지의 기준이다.** 영상 편수는 레슨당 예제 개수에 좌우되므로 비교축으로
부적절하다. 기간이 길수록 다루는 주제가 늘어난다: 6개월 426 → 1년 512.

**레벨이 올라가면 편수가 준다.** 배치 테스트를 통과한 단원을 건너뛰기 때문이다.

**하루 분량은 트랙 비중으로 나눈다.** `tracks[].daily_min`은 고정 분량이 아니라 비중이며,
같은 날 겹치는 트랙끼리 `daily_total_min`을 비중대로 나눠 갖는다. 어떤 날도 약속한 분량을 넘지 않는다.
