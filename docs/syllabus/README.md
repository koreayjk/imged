# 실라버스

기간 4종 × 방식 2종 × 레벨 3종 = **24종**. 모두 `scripts/generate_syllabus.py`가
`config/durations.json`·`config/ged_scope.json`·`config/levels.json`에서 자동 생성한다.
손으로 고치지 말고 설정을 고친 뒤 다시 생성할 것.

```
python3 scripts/generate_syllabus.py            # 전체
python3 scripts/generate_syllabus.py 1y focus   # 기간·방식·레벨 키로 부분 생성
```

## 어디에 무엇이 있나

| 경로 | 내용 |
|---|---|
| `docs/syllabus/실라버스_<기간>_<방식>_<레벨>.md` | 주차·일자별 상세. 영상 제목과 YouTube 링크까지 |
| `docs/syllabus/제외목록_<기간>_<방식>_<레벨>.md` | 제외된 영상과 그 사유 |
| `docs/syllabus/영상선별_<코스>.md` | 코스별 포함·제외 판정 근거 |
| `docs/syllabus/_검증_리포트.md` | 트랙별 배치 결과와 조정 필요 사항 |
| `data/syllabus/<기간>_<레벨>_<방식>.json` | 앱이 읽는 원본. 화면에 그대로 반영된다 |

## 숫자 읽는 법

**주제(레슨) 수가 커버리지의 기준이다.** 영상 편수는 3년 과정이 2년보다 적게 나오는데,
이는 3년이 훨씬 넓은 범위를 다뤄 주제당 예제 영상이 줄어든 결과다. 기간이 길수록
다루는 주제가 늘어난다: 속성 335 → 1년 449 → 2년 620 → 3년 816.

**레벨이 올라가면 편수가 준다.** 배치 테스트를 통과한 기초 단원을 건너뛰기 때문이다.

**하루 분량은 트랙 비중으로 나눈다.** `tracks[].daily_min`은 고정 분량이 아니라 비중이며,
같은 날 여러 트랙이 겹치면 `daily_total_min`을 비중대로 나눠 갖는다. 그래서 어떤 날도
약속한 하루 분량을 넘지 않는다.
